# CodeSDK

Developer tools for building CodeOS applications.

| Component | Path | Description |
|-----------|------|-------------|
| CLI | `cli/` | `codeos new`, `build`, `run`, `docs` |
| Templates | `templates/` | App scaffolds (`.capp` + `codeos_manifest.toml`) |
| Docs | `docs/` | SDK documentation index |

See [docs/SDK_OVERVIEW.md](../docs/SDK_OVERVIEW.md).
