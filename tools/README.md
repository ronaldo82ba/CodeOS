# CodeOS Build Tools

Supporting tools for building and packaging CodeOS.

| Tool | Path | Description |
|------|------|-------------|
| cpk-packer | `cpk-packer/` | Packages apps into `.cpk` archives |
| boot-simulator | `scripts/boot-simulator.sh` | Starts Simulator + services |
| build-image | `scripts/build-image.sh` | Builds QEMU boot image (v0.2) |
